## Steps

1. Ask the user what's the main problem they need to solve
2. Ask questions in order to understand the scope of the problem and the possible solutions
3. Keep asking questions until you have a clear understanding of the problem 
4. Create an issue in the issue folder as markdown file with a number and a name, also add metadata in the frontmatter like tags, severity, status
5. Present a short summary of the newly created issue
