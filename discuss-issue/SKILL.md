# Steps
 
1. Read the issue in the issues folder for the given issue number
2. Check if the issue is still valid reading the source code of the project
3. Don't jump ahead to solve it but present the situation and the possible solution you can think of, take into account common practice and pattern and if this problem have common solution done by other similar projects or software.+
4. List the solution you found and update the issue with them
5. Ask the user which one they want to discuss
